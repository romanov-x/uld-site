# ULD — Уральская Лига Дрифта (главная страница)

Статическая вёрстка главной страницы: HTML + CSS + немного JS, без сборки и зависимостей.

- `index.html` — разметка по БЕМ
- `css/style.css` — стили, брейкпоинты: 1480+ / 1024–1479 / 768–1023 / до 767
- `js/main.js` — появление блоков при прокрутке, таймер, счётчики, мобильное меню, шапка
- `img/` — логотип и фавиконка

Запуск локально: открыть `index.html` в браузере или `python3 -m http.server`.

Содержимое демонстрационное: цены, программа и таймер условные, вместо фото — заглушки.
Для реального таймера задайте `data-deadline="2026-09-27T12:00:00+05:00"` у блока `.countdown`.
